## 架构与工程总览

结合下游信用（Credit）流控的字节级赤字轮询（DRR）调度器，支持每队列独立配额（Quantum）累计与运行时无毛刺权重重配置。

| 维度 | 已验收工程交付物 |
| :--- | :--- |
| **可综合 RTL 模块 (`rtl/`)** | [`rtl/credit_scheduler.sv`](rtl/credit_scheduler.sv) |
| **回归验证与签核记录** | 15 轮随机种子回归 · 145,884 仿真周期 · 5,544 笔数据包公平调度完成 |
| **开源协议** | [MIT License](../../LICENSE) |

## 快速编译与语法检查

使用 Icarus Verilog (`iverilog -g2012`) 对 `rtl/` 下的可综合 SystemVerilog 源码执行编译检查：

```bash
iverilog -g2012 -t null rtl/*.sv
```

完整的英文接口时序、参数定义与微架构说明请参阅英文文档 [`README.md`](README.md)。
